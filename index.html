ShapeFu is a mobile game available on supported platforms including Android and iOS.

ShapeFu can be played offline for core gameplay functionality. The game does not require user accounts and does not use developer-owned backend servers.

The underlying software architecture, code, and systems may be reused, modified, or deployed in other applications by the developer.

Gameplay data is stored locally on the user's device only, including:

  • Progress and unlocks

No gameplay data is transmitted to external servers operated by the developer.

4. User Accounts

ShapeFu does not require account creation or login.
